# 🚀 Heavenly Client Auth Backend

Облачная система аутентификации, привязки по HWID, выдачи UID и управления подписками для лоадера **Heavenly 1.21.11**.

---

## ⚡ Быстрый старт (Локально на ПК)

1. Дважды кликните по `run.bat` (или запустите команду):
   ```cmd
   python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```
2. Сервер запустится на адресе `http://127.0.0.1:8000`.
3. Лоадер `loader/HeavenlyLoader.exe` автоматически подключается к этому адресу!

---

## 🌐 Как бесплатно запустить в облаке 24/7 (Работает в РФ, 0 рублей)

Для того чтобы лоадер работал у всех ваших друзей и клиентов без включенного ПК:

1. Зарегистрируйтесь на **[Render.com](https://render.com/)** (не заблокирован в РФ, бесплатный тариф).
2. Создайте новый **Web Service**.
3. Подключите ваш репозиторий с папкой `backend` (или загрузите файлы).
4. Укажите:
   - **Environment:** `Python`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. Render выдаст вам бесплатную ссылку вида:
   `https://heavenly-auth.onrender.com`
6. Вставьте эту ссылку в файл `loader/api_url.txt` рядом с `HeavenlyLoader.exe` — всё, лоадер теперь работает через интернет!

## 👑 Аккаунт владельца по умолчанию (UID 1)

При первом старте база автоматически создаёт аккаунт создателя:
- **Логин:** `HeavenlyOwner`
- **Пароль:** `admin123`
- **UID:** `1`
- **Роль:** `Owner`
- **Подписка:** `LIFETIME` (Бессрочная)

---

## 🔑 Тестовые ключи активации

В базе уже созданы ключи для активации через экран лоадера (кнопка *"У меня есть ключ"*):
- `HV-LIFE-TIME-2026` — Навсегда (Lifetime)
- `HV-30DAY-PASS-0002` — 30 дней
- `HV-07DAY-TRIAL-001` — 7 дней

---

## 🛠️ Админ-панель и документация Swagger

Откройте в браузере: `http://127.0.0.1:8000/docs`

Доступные админ-методы:
- `POST /api/admin/create_key` — создание новых ключей подписки (указываете количество дней и префикс).
- `POST /api/admin/reset_hwid` — сброс привязки HWID по логину (если пользователь сменил ПК).
- `GET /api/admin/users` — список всех пользователей, их UID, HWID и статус подписки.
